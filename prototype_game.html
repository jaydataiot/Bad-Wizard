Game Concept

This prototype is being developed as a high-interaction tabletop game focused on player decisions, shifting alliances, unexpected consequences, and memorable narrative moments.

Core Experience

Every Choice Changes the Table

Players pursue competing goals while responding to shared events, limited resources, and changing relationships. Success depends on planning ahead, reading opponents, and knowing when to cooperate or betray.

Design Goal

Fast Rules, Deep Consequences

The game is designed to be easy to teach while still creating strategic depth through card interactions, player powers, and evolving board conditions.

Prototype Features

These systems are currently being tested and may change as the game develops.

Asymmetric Roles

Each player begins with a different ability, agenda, or advantage that encourages distinct strategies.

Dynamic Events

Events alter the board, introduce new threats, and force players to adapt their plans.

Negotiation

Players may trade resources, make temporary alliances, and create deals that are not always guaranteed to last.

Resource Management

Limited resources must be invested carefully to unlock actions, upgrades, and scoring opportunities.

Multiple Paths to Victory

Players can pursue different scoring strategies rather than relying on one fixed route to win.

Replayable Stories

Variable setup, randomized events, and player interaction produce a different story each time the game is played.

Playtest Program

Help Shape the Game

Bad Wizard Games uses player feedback to improve rules, balance, pacing, accessibility, and replayability before a game enters production.

  • Test early builds and revised rule sets.
  • Report unclear rules, balance problems, and edge cases.
  • Share feedback about theme, pacing, and player interaction.
  • Receive recognition when appropriate in project credits.
Prototype materials, artwork, names, mechanics, and release details may change before publication.
