# Bad-Wizard

🧙 Bad Wizard Games

Bold. Twisted. Unforgettable.

Welcome to the official repository for Bad Wizard Games, an independent board game studio dedicated to creating unforgettable tabletop experiences through original storytelling, immersive themes, and innovative mechanics.

Website: https://www.badwizard.games

⸻

About

Bad Wizard Games designs board games that blend strategy, horror, humor, mystery, satire, and narrative into experiences unlike traditional tabletop games.

Every title is handcrafted to create memorable moments around the table rather than simply moving pieces on a board.

Our mission is simple:

Create games that people remember years after they’ve played them.

Board Game Archive (In Development)

One of the largest features currently under development.

The archive combines:

* Large board game datasets
* Dynamic web research
* AI profiling
* Metadata collection
* Image gathering
* Recommendation engines

Instead of displaying static information, the archive builds a profile for the selected game and dynamically collects additional information from multiple online sources.

Every search helps expand the archive over time.

Planned information includes:

* Images
* Publisher information
* Designers
* Mechanics
* Player counts
* Complexity
* Ratings
* Historical information
* Similar games
* Community discussions
* Reviews
* Videos
* Market information

⸻

Set the Scene

An AI-powered experience that helps players create the perfect atmosphere before game night.

Using inputs such as:

* Game being played
* Number of players
* Time of day
* Season
* Geographic location

The system generates recommendations for:

* Music
* Food
* Lighting
* Decorations
* Clothing
* Drinks
* Party themes
* Ambient effects

Current Games

Cult Leader

A strategic game of manipulation, recruitment, and influence where players build dangerous organizations while avoiding government attention.

⸻

Double Wide

Trailer park politics, outrageous neighbors, and southern humor collide in a highly interactive strategy game.

⸻

Grab-A-Ghost

An adult horror party game where investigators race to capture violent spirits while sabotaging one another using cursed relics, rituals, and supernatural abilities.

⸻

10.31.84

A horror experience containing multiple interconnected stories with hidden narrative paths waiting to be discovered.

⸻

F.A.F.O.

A comic-book inspired strategy game set in the crime-ridden streets of Cotton City.

Players fight for control of neighborhoods, recruit allies, own businesses, survive betrayals, and navigate shifting alliances as the city changes hands.

⸻

Blood Suckers

A futuristic vampire strategy game set in a world where advanced technology has nearly driven vampires to extinction.

Players secretly rebuild their covens while infiltrating governments and megacorporations.

⸻

Pixel Cooperative

A cooperative city-building experience where players work together to restore and expand a growing pixel world.

⸻

Slasher

An intense horror survival game inspired by classic slasher films where nobody is ever truly safe.

⸻

The Judge’s Eye

A mystery and deduction game where evidence, intuition, and deception determine justice.
