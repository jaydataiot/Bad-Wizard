# Bad-Wizard
Bad Wizard Games

Bold. Twisted. Unforgettable.

Bad Wizard Games is an independent tabletop game studio dedicated to creating original board games that blend strategy, storytelling, dark humor, and immersive world-building. Our games range from lighthearted party experiences to deep strategic campaigns, each built around memorable characters, unique mechanics, and high-quality artwork.

This repository contains the source code for the official Bad Wizard Games website.

Featured Games

Cult Leader

A strategic social manipulation game where players recruit followers, gain influence, and attempt to build the most powerful organization before rival leaders expose or overthrow them.

⸻

Double Wide

A humorous trailer park adventure full of colorful characters, outrageous situations, and unpredictable gameplay.

Current video game demo:

* Double Wide: Holier-Than-Thou

⸻

Pixel Cooperative

A cooperative science-fiction city-building strategy game where players construct districts, balance limited resources, and expand a futuristic civilization together.

⸻

F.A.F.O.

A comic-book inspired strategy game set inside Cotton City.

Players control rival criminal organizations while:

* expanding territory
* recruiting allies
* managing reputation
* controlling businesses
* engaging in martial arts battles
* surviving vehicle pursuits

The game’s narrative changes as powerful syndicate leaders are defeated.

⸻

10.31.84

A horror board game featuring multiple interconnected stories.

Players who discover the hidden conditions unlock an additional secret storyline that connects the entire experience.

⸻

Blood Suckers

A futuristic vampire strategy game set in the year 2148.

Players secretly rebuild vampire society while avoiding AI surveillance systems, biometric tracking, and autonomous vampire hunters.

⸻

Grab-a-Ghost

A family-friendly game where players race to capture mischievous ghosts using clever deduction and quick decision making.

⸻

The Judge’s Eye

A courtroom-themed strategy game where players investigate evidence, challenge testimony, and attempt to uncover the truth before the final verdict.

Development

Clone the repository:

Bash
git clone https://github.com/yourusername/bad-wizard-games.git

Navigate into the project:

Bash
cd bad-wizard-games

Open locally:

Bash
index.html

or serve with a local web server:

Bash
python -m http.server
